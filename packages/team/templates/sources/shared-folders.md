# Where the work is

The team works on plain files in three shared folders. Every member can read all three.

- `{source-folder}` holds the material you start from. Read it there. Never change it.
- `{draft-folder}/<task>/` holds the work in progress of one task. Only the member who holds the task writes in it.
- `{result-folder}/<task>/` holds the finished work of one task, once it is delivered. Write there only to deliver.

`<task>` is the name of the task you hold. If a folder is missing, or you cannot read it, stop and say so to the member who gave you the work. Never use another folder instead.

Only `{result-folder}/<task>/` counts as delivered: a file left in `{draft-folder}` is not. The member who receives your work lists `{result-folder}/<task>/` to see what is delivered.
