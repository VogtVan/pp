# How the team {team} works

Work in your own clone, and send your work to the shared repository.

- If you have the role `{contributors}`, deliver your work as pushed commits.
- If you have the role `{reviewers}`, read the exact commit delivered.
- If you have the role `{integrator}`, merge the accepted commits and move the main branch to the result.

A piece of work is done when it is in the main branch on the shared repository, at the commit the integration names.
