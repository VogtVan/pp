# How the team {team} works

Keep one branch per plan; only the member who holds the plan writes on it.

- If you have the role `{contributors}`, deliver your plan's work as pushed commits on its branch.
- If you have the role `{reviewers}`, read the exact commit delivered.
- Never move the main branch: it moves outside the team.

A delivery is done when its commit is on the shared repository and its review says `accepted`.
