# How the team {team} works

Work on plain files in the shared folders. Do not use Git for the team's work.

- If you have the role `{contributors}`, write the work and deliver it by copying it to the results folder.
- If you have the role `{reviewers}`, check each delivery, then review it.

A piece of work is done when its delivery is checked and its review says `accepted`.
