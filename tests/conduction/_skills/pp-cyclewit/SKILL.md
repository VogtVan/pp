# pp-cyclewit

Two faces, both deterministic: `next` prints the first of alpha, beta, gamma not yet marked
done in `cyclewit.done` beside the instance (`PP_HOME`), nothing when none is left; called as
a SINK (the production on stdin) it marks done the element the production names.
