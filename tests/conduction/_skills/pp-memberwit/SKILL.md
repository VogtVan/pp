# pp-memberwit

One face, deterministic: `grow` rewrites `MEMBER.md` beside the instance (`PP_HOME`) as the member
craft does -- `# SERVE` becomes `SERVE` and a `serve:` row names `LINES.txt` -- while MEMBER is a
frame of the run; a member already grown is left as it is. The set's `keep:` puts the member back
before the next exchange.
